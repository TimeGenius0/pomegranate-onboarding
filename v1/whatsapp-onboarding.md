# WhatsApp bot onboarding

**What to collect:** the user's WhatsApp phone number in international format, including country code (for example, `+1 555 010 1234`).

**What Pomegranate provides:** register that number to the user's account and give them the agent number **+1 510 697 6636**.

**Tell the user:**

1. Save **+1 510 697 6636** in WhatsApp under the agent name they choose.
2. Message that contact to use Pomegranate.
3. Example: “Create a folder for customer Toyota Moros and add this message to it: …”

Do not publish the user's phone number. If registration requires a setup request, show the user the email before sending it and send only after explicit approval.
