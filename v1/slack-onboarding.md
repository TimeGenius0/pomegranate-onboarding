# Slack bot onboarding

**Tell the user first:** a Slack administrator must install the bot and approve its permissions.

**Collect:**

- Slack workspace URL
- Slack admin contact or installation access
- Bot name (logo optional)
- Bot credentials: `xoxb-…` plus `xapp-…` for Socket Mode, or an HTTP signing secret
- Slack member ID for each person who will use the bot

If some details are missing, send what is available and mark the rest pending. Ask for approval before sending a setup request to Pomegranate. Credentials must be shared securely with the Pomegranate team, never in a relayed channel.
