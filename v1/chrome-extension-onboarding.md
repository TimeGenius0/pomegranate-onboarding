# Chrome extension onboarding

**Requirement:** the user's Pomegranate account and a connection token issued for their workspace.

**Setup:**

1. Install [Pomegranate from the Chrome Web Store](https://chromewebstore.google.com/detail/njkhjadbdlbadhkhjfhpgdiikjkonmek?utm_source=item-share-cb).
2. Open the extension's settings and choose **Connect via app.pomegranate.expert**.
3. Sign in at the [connection page](https://app.pomegranate.expert/?returnTo=connect) and issue a connection token; the extension picks it up through the one-click connection flow.
4. On any page, select text or open the extension to **Add**, **Ask**, or **Review** against the connected folder.

Never publish a connection token.
