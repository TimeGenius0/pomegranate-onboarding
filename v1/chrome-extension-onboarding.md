# Chrome extension onboarding

**Requirement:** the user's Pomegranate account email, plus confirmation that Pomegranate has enrolled the account. The extension is currently an unlisted alpha; there is no public Web Store install link.

**Setup:**

1. Send the user to the [connection page](https://app.pomegranate.expert/?returnTo=connect) and have them sign in.
2. From Setup, issue a connection token; the extension picks it up through the one-click connection flow.
3. Install the invited extension link supplied by Pomegranate.
4. On any page, select text or open the extension to **Add**, **Ask**, or **Review** against the connected folder.

If the account is not enrolled, ask for approval before requesting access from the Pomegranate team. Never publish a connection token.
